# API reference

## Imports

```python
from advancedprinter import (
    AdvancedPrinter,
    Printer,
    MessageStyle,
    ColorFormatter,
    print,
    input,
    line,
    frame,
    help,
    success,
    warning,
    error,
    info,
    format_text,
    format_frame,
    strip_ansi,
    visible_width,
)
```

`AdvancedPrinter` preserves class-style calls and the original
`advancedprinter.main.AdvancedPrinter` import path. `AdvancedPrinter.C` retains
the original ANSI constants. New configuration belongs to a `Printer` instance.
All public functions are typed; the wheel includes `py.typed`.

## Printer configuration

`Printer(*, color_mode="auto", color_system="auto", file=None, error_file=None, theme=None)`

| Parameter | Values / behaviour |
|---|---|
| `color_mode` | `auto`, `always`, `never` |
| `color_system` | `auto`, `standard` (16 colours), `256`, `truecolor` |
| `file` | Default output stream; `None` means current `sys.stdout` |
| `error_file` | Default destination of `error()`; `None` means current `sys.stderr` |
| `theme` | Partial mapping of `success`, `warning`, `error`, `info` to `MessageStyle` |

A call's explicit `file=` overrides the instance stream. Output methods also
accept per-call `color_mode` and `color_system` overrides. Explicit `always`
overrides `NO_COLOR` and stream detection; automatic mode does not.
In automatic mode, `COLORTERM=truecolor` or `24bit` selects truecolour,
`TERM` containing `256color` selects 256 colours, otherwise standard colours are
used. RGB and indexed colours are approximated for the selected depth. Standard
ANSI colours use the terminal's palette, which may differ from the conventional
RGB palette used for approximation. Environment detection is a heuristic; force
a depth if your terminal advertises incomplete information. Pure inline spans
are already-rendered strings and retain their original colour depth.

## Printing and text formatting

`Printer.print(*values, ...)` and module-level `print(*values, ...)` return `None`.

| Parameter | Default | Meaning |
|---|---|---|
| `c` / `color` | `None` | Foreground name, `#RRGGBB`, RGB tuple, or xterm index |
| `b` / `background` | `None` | Background specification |
| `s` / `style` | `None` | Styles separated by spaces, commas, or legacy hyphens; list/tuple also accepted |
| `sep` | `" "` | Separator between stringified values; `None` uses the default |
| `end` | `"\n"` | Text appended after the values; `None` uses the default |
| `file` | instance stream | Destination used for both detection and output |
| `flush` | `False` | Flush output immediately |
| `color_mode` / `color_system` | instance settings | Per-call policy overrides |

Supplying both an alias and its long name with different values raises
`TypeError`. Unknown colours/styles raise `ValueError`, even when output is
plain. Colours `0` and `(0, 0, 0)` are valid. RGB channels and indexes must be
integers, excluding booleans. Names are case-insensitive. `default` selects the
terminal's default foreground/background.

`format_text(*values, ...)` returns a string; `line` is its alias. They support
the styling arguments above, `sep`, `end=""`, `color_mode="always"`, and
`color_system="truecolor"`; they have no stream/flush arguments and reject `auto`.
`Printer.line`, `Printer.format_text`, and `Printer.format_frame` are the same
pure functions, independent of instance output policy.

Nested formatted spans restore enclosing formatting on full or selective resets.
This is intended for SGR styles generated by this library, not as a complete
terminal emulator or sanitiser for untrusted terminal content.

## Frames

`format_frame(text, f_s=None, f_c=None, f_b=None, c=None, b=None, s=None, *, ...)`
returns a string with no trailing newline. The first seven positional arguments
remain compatible with 1.x. `frame()` prints the rendered frame and returns `None`.

| Parameter | Default | Meaning |
|---|---|---|
| `f_s` / `border` | `basic` | `basic`, `basic2`, `single`, `double`, `rounded` |
| `f_c` / `border_color` | text foreground | Border foreground; use `default` to opt out of inheritance |
| `f_b` / `border_background` | text background | Border background |
| `c` / `color`, `b` / `background`, `s` / `style` | `None` | Content styling |
| `title` | `""` | Single-line title in the top border |
| `padding` | `1` | Horizontal padding on each side, in cells |
| `width` | natural width | Exact total width including borders and padding |
| `max_width` | no limit | Upper bound on total width |
| `wrap` | `True` | Wrap by display cells, preserving whitespace and ANSI spans |
| `align` | `left` | `left`, `center`, `right` |
| `dedent` | `False` | Remove common leading indentation |
| `ascii` | `False` | Use the basic ASCII border |

Pure frames use `color_mode="always"`, `color_system="truecolor"` and reject
`auto`. Printed frames use the printer policy and accept `file`, `end`, and
`flush`. Widths must leave at least one cell for content. A title that does not
fit, a grapheme wider than the available space, or overflow with `wrap=False`
raises `ValueError`. No truncation is performed. Tabs expand to four spaces;
unsupported control characters are rejected. Empty content produces an empty
frame. Blank lines and trailing newlines are preserved. Default padding is
horizontal only. Terminal-specific emoji rendering may still vary.

## Input and semantic messages

`input(prompt="", /, *, c=None, b=None, s=None, color=None, background=None, style=None)`
writes the stringified prompt without stripping whitespace, flushes the printer's
output, then reads from Python's standard input. It returns the entered string.
It accepts at most one positional prompt. EOF and keyboard interrupts propagate.

`success`, `warning`, `info`, and `error` accept `*values`, `sep`, `end`, `file`,
and `flush`. The default visible prefixes are `[SUCCESS]`, `[WARNING]`, `[INFO]`,
and `[ERROR]`; labels remain meaningful without colours. `error()` uses stderr
unless its own stream is supplied or `error_file` is configured.

`MessageStyle(color=None, style=None, prefix="")` is an immutable theme entry.
Theme dictionaries are copied per instance. A partial theme overrides only the
specified message kinds. An empty prefix omits the label.

## Logging and utilities

`ColorFormatter(fmt=None, datefmt=None, *, stream=None, color_mode="auto", color_system="auto")`
colours the final formatted log entry, including tracebacks. `stream=None`
means the current stderr; normally pass the actual `StreamHandler.stream`.
DEBUG is grey, INFO cyan, WARNING yellow, ERROR/CRITICAL bold red. A copied
record is formatted so other handlers keep their own original record and
exception formatting. It does not create handlers or change logger configuration.

`strip_ansi(text)` removes ANSI sequences including CSI and OSC hyperlinks.
`visible_width(text)` returns terminal display cells ignoring ANSI; control
characters with indeterminate width raise `ValueError`.
`help(file=None)` prints the palette and style names with the output policy.
